# Sicherheit

Wenn dir eine Sicherheitslücke auffällt, melde sie bitte nicht als öffentliches Issue, sondern über „Report a vulnerability“ im Tab [Security](https://github.com/MHabachia/markitdown-desktop/security/advisories/new). Ich schaue mir jede Meldung an und melde mich so bald wie möglich.

Unterstützt wird jeweils nur die neueste Version. Die App aktualisiert sich selbst, solange die Update-Suche in den Einstellungen eingeschaltet ist.
